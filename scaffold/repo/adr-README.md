# Architecture Decision Records — this article

One file per article-scope decision (notation, reference policy, a cut, a release form), append-only,
on the hub's format (`Notes/adr/README.md`): `NNNN-title.md` with Status, Mechanism, Context,
Decision, Consequences. Never edited once accepted; a changed decision is a new ADR that supersedes
the old one. A decision that binds every article belongs in article-kit's `adr/`; one about the wiki
or the programme in the hub's.
